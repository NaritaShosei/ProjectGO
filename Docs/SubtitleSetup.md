# 字幕の設定と確認

`Assets/Data/SubtitleSettings.asset` をUnityのInspectorで編集します。
GOTestSceneなどの既存の `Canvas` 直下に `SubtitleText` を事前配置し、SequenceManagerのSubtitle Viewに接続しています。実行時にUIを生成しません。位置・フォント・サイズは配置済みText UIで調整します。
既存の `AssetsLoader.LoadAssetAsync` でAddressablesアドレス `SubtitleSettings` を読み込み、完了後にゲームを初期化します。Default Local Groupに登録済みです。
シーンごとに設定を分ける場合は、このアセットを複製してAddressablesに登録し、SequenceManagerのSubtitle Settings Addressにそのアドレスを指定します。

## 表示対象

- スキルを選択して次のウェーブが正常に始まった後、獲得順に1〜6のセリフを表示します。初期設定では2秒後に音声と字幕を同時に開始します。
- 初期所持スキル、ステータス強化、候補がなく選択を省略した場合は数えません。7回目以降は追加のセリフを再生しません。
- モブ戦のダウン回復完了時は、実際に再生された復活ボイスと同じセリフを表示します。復活スキルでは表示しません。
- ゲームオーバー画面表示を基準に、HP切れ・時間切れとも「こんなところで…」の字幕とボイスを同時開始します。死亡時の即時ボイスはここに統合しています。
- 導入ムービーの再生成功を基準に、初期設定では10秒後に「お前たちを許さない！！」を字幕とボイスで同時開始します。現在の約13.5秒の映像終盤に合わせた値です。
- リザルト画面表示を基準に「もう迷わないこの力で私は戦う！」を字幕とボイスで同時開始します。
- 導入・リザルト・ゲームオーバーのDelayは初期値から自由に変更できます。導入のDelayは映像が終了する前に設定してください。Timelineの音声トラック・Signalには設定しません。
- 攻撃、被弾、モードチェンジの字幕は表示しません。

## 調整項目

各Lines要素のTextを編集すると文章を変更できます。Cue Nameは音声との対応キーなので維持してください。

| 項目 | 内容 |
| --- | --- |
| Delay | トリガーから字幕が出始めるまでの秒数。スキル獲得・導入・リザルト・ゲームオーバーは音声も同時に開始します。復活は既存の音声再生が基準のため字幕のみ遅延します |
| Duration | フェードを除いた表示継続秒数 |
| Fade In / Fade Out | 表示・非表示にかける秒数。0なら即時切り替え |
| Font / Font Size | 日本語フォントと文字サイズ |
| Bottom Margin / Panel Height | 1920×1080基準の下端からの余白と背景パネルの高さ |

字幕はゲームの時間倍率に左右されない実時間で進行します。同時に表示する字幕は1件で、新しい要求が来ると前の字幕と予約・再生中の字幕ボイスを置き換えます。スキル選択開始、シークエンス切り替え、ムービー終了・スキップ、タイトルへ戻る操作、無効化時にも停止します。字幕の表示時間満了だけでは音声を途中で切りません。字幕UIの参照が欠けた場合も、音声のDelayは維持します。

## Unityでの確認手順

1. 通常のインゲームシーンを開始し、初回ウェーブではスキル字幕が出ないことを確認します。
2. スキルを選択し、次ウェーブ開始2秒後に対応する字幕とボイスが1回出ることを確認します。時間切れの自動選択も同様です。
3. モブ戦でHPを0にし、起き上がり完了時のボイスと字幕の文章が一致することを確認します。
4. HP切れとボス戦時間切れの両方で、DeathVoiceのDelay後に音声と字幕が一度だけ同時開始することを確認します。
5. Delayを長くして待機中にシークエンスを切り替え、古い字幕が出ないことを確認します。
6. Text、Delay、Duration、Fade In、Fade Outを編集して反映を確認します。画面下部のHUDやボタン操作に干渉しないことも確認します。
7. IntroMovieVoiceのDelayを変更し、ムービー開始から指定秒数後に音声と字幕が同時開始することを確認します。待機中・再生中の両方でスキップし、次シークエンスに音声が残らないことを確認します。
8. ResultVoiceのDelayを変更し、リザルト画面表示から指定秒数後に音声と字幕が同時開始することを確認します。待機中・再生中にタイトルへ戻り、音声が残らないことを確認します。

台詞の出典: [セリフ字幕表記](https://tranquil-boron-1d2.notion.site/3c74b62c600d80b887f2d7f60feb3613)。使用キューは配布ACBに存在する `IntroMovieVoice`、`ResultVoice`、`DeathVoice` です。

現在の音声データに合わせてキュー名は `SkillGetVoice01` などの形式です。小ダメージ2だけは配布ACB上の表記 `DamageVoiceSmal02` に合わせています。
